## 垫片解决过的问题清单（排错索引）

| 症状 | 根因 | 修法（已在垫片中） |
|---|---|---|
| FPSMeter is not defined | index.html 缺 lib 引用 | ai_test.html 补 script |
| ENOENT /OMORI/CUTSCENE.json | 读 %LOCALAPPDATA% | 虚拟目录 + 预置空 JSON |
| steamworks.initAPI 报错 | Steam 集成 | 桩返回 false（游戏自动降级） |
| crypto/Buffer 报错 | 加密数据路径 | 用 `?test` 走明文，绕开 |
| **画面黑、帧数为 0** | `SceneManager.isFocus()` 查 `window.top.hasFocus()` 内嵌环境永远 false → **场景更新/输入/渲染全跳过**（教程知识库警告的"失焦即停"） | 覆写 `isFocus=()=>true` |
| rAF 永不回调 | 无焦点环境浏览器暂停 rAF | 500ms 自检降级为 setTimeout + 重启 PIXI ticker |
| goto 无效回到闪屏 | GALV 闪屏插件劫持所有 goto | `Galv.ASPLASH.splashed = true` |
| 存档读写 | nw 文件存储 | 浏览器 localStorage / 内存覆盖层（当次会话有效） |

## 边界（不能测什么）

- **手感/节奏**：帧率仅 6fps，逐字动画时序、音画同步仍需人工在引擎里验收
- **音频**：无用户手势时 WebAudio 被浏览器锁（能跑不发声，不报错）
- Steam 成就 / OneLoader mod 注入 / 存档落盘
- `render/` 缩略图等工具产物不参与运行
