# OMORI 原作战斗系统解剖（2026-10-03）

> 数据源：data/States.json / Skills.json / System.json / Actors.json / Items.json / CommonEvents.json + js/plugins（Omori Battle System / Omori BASE / GTP_OmoriFixes / YIN_OmoriFixes / Active Chain Skills / Custom Battle Action Text / Anti Fail Actions）。
> 注意：States/Skills/CommonEvents 是条目一行格式，**条目 id N 在第 N+2 行**。
> **重要纠错：原作没有攻击时机条/PERFECT 判定**（见 §4）——AI 测试里看到的 actionList 长等待实为 ACS 追击 120 帧输入窗口。

## 1. 情绪系统

### 1.1 情绪 = MV 状态，各 3 级
- HAPPY 6/7/8、SAD 10/11/12、ANGRY 14/15/16、AFRAID 18（仅 1 级）。
- 升级判定：GTP_OmoriFixes:719-736 `isEmotionAddable(type)`（1级→加2级状态，2级→3级）。
- 全部情绪状态：GTP_OmoriFixes:689-691 `[6,7,8,10,11,12,14,15,16,18]`。
- **降级免疫**：高级状态带 State Resist 抗低级（ECSTATIC 抗 6；MANIC 抗 6,7……）。
- **同时只能一种情绪**：每个情绪 note `removeStateCategoryAll("HAPPY"/...)`；死亡(状态1)清空全部。
- **不自动过期**：`autoRemovalTiming:0`，`removeAtBattleEnd:true`。
- 敌人伪情绪状态：Space Ex-Boyfriend ANGRY=119-121、Sweetheart HAPPY=122/123/197、Unbread Twins SAD=124-126（GTP:738-757 并入判定）。
- **敌人情绪可视化=换贴图**：Omori BASE:2745-2776，TransformBaseID：happy=base+1、sad=+2、angry=+3（note `<TransformEmotion>`）。

### 1.2 克制环（元素倍率实现）
元素表：2=HAPPY、3=SAD、4=ANGRY、5=EMOTION(通用)、6=AFRAID。

**SAD 克 HAPPY、ANGRY 克 SAD、HAPPY 克 ANGRY**。等级越高抗性越强、弱点也越痛：

| 受击方 | 抗性(×) | 弱点(×) |
|---|---|---|
| HAPPY 1/2/3级 | ANGRY 0.8/0.65/0.5 | SAD 1.5/2/2.5 |
| SAD 1/2/3级 | HAPPY 0.8/0.65/0.5 | ANGRY 1.5/2/2.5 |
| ANGRY 1/2/3级 | SAD 0.8/0.65/0.5 | HAPPY 1.5/2/2.5 |
| AFRAID | 无 | 全情绪元素 ×1.5 |

普攻吃克制的补丁：YIN_OmoriFixes:38-70 重写 `calcElementRate`——施法者处于情绪状态时，普攻（elementId=0）按其情绪攻击元素（trait code:31 提供 2/3/4）计算倍率。
克制反馈：「迅捷一击！/疲软一击。」文案（Custom Battle Action Text:81-85）+ 专属音效（YIN:95-103）。

### 1.3 情绪对属性的影响（traits）
- **HAPPY**：HIT -10%/-20%/-30%（更易失误但更易打中弱点）、LUK ×2/3/4、AGI ×1.25/1.5/2。
- **SAD**：DEF ×1.25/1.35/1.5、AGI ×0.8/0.65/0.5；**受伤转 JUICE**（HP 伤害的 30%/50%/100% 转为 MP 扣除，note Custom React Effect）。
- **ANGRY**：ATK ×1.3/1.5/2、DEF ×0.5/0.3/0.15。
- **AFRAID**：封印技能类型 1（=全队所有主动技能）→ 只能普攻/防御/道具。**OMORI 永久免疫 AFRAID**（Actors actor1 traits）。
- 暴击不受情绪影响（无 CRI trait）；暴击伤害 ×3（rpg_objects:1760-1762）；技能普遍 ±20% 方差。

## 2. JUICE = MV 的 MP
- 技能消耗字段就是 `mpCost`（悲伤的诗 5、雪球 20、红手 75）；TP 未用。
- 上限 = maxmp 等级曲线（OMORI Lv10=50、Lv50=239），无固定值。
- 恢复：果汁道具（30 个 type:4 物品：梅子汁+15、樱桃汽水 25%mmp……）+ HERO/KEL 回复技 + **被 SAD 系打反而掉 JUICE**。防御不回、无自动回复。

## 3. FOLLOW-UP（追击）与 RELEASE ENERGY

### 框架：TDS Active Chain Skills（ACS）
- 技能 note `<ChainSkill: SkillId, Input>`（方向键→接续技）；`<ChainOnly>` 限连段内可用。
- 流程：普攻后弹链技气泡 → **120 帧输入窗口**（ACS:117-118 minimunInputTime）→ 按方向键且已学会可用 → 插入行动队列。
- 入口在普攻上：OMORI 攻击(技21) up=46 再次攻击/right=49 绊倒/down=52 RELEASE ENERGY；AUBREY 64、KEL 103、HERO 143 同理。
- 实际效果经公共事件强制动作（code 339）实现，按习得开关选升级版（CE935 ATTACK AGAIN 48/47/59 三档）。
- 追击伤害吃 LUK：LOOK OMORI 系列 `(a.atk*2+a.luk)-b.def` → `a.atk*3+a.luk`。

### ENERGY（全队共享，上限 10）
- 战斗开始 3 点；**己方每受一次伤 +1**（打敌人不涨）。
- 带 `<EnergyCost:N>` 技能扣队内 ENERGY（普通追击 3 点）。
- **RELEASE ENERGY**：down 键触发，需满 10 点 + 三队友存活 → 合体动画 → 全体敌人固定伤害（技能55=1000 / 技能53=300 按版本）。

## 4. ⚠ 纠错：原作没有"攻击时机条"

全插件 grep `perfect/timing` 零命中（战斗相关）。原作全部战斗按键只有：
1. **ACS 追击方向键**（120 帧窗口——战斗中"攻击后长等待"的真相）；
2. 目标选择 Shift 切群体；
3. 等待按 OK。

伤害档位只有：暴击(×3) > 克制(×1.5-2.5) > 普通 > 被克(×0.8-0.5) + ±20% 方差 + MISS/EVADE。**不存在玩家按键决定的 PERFECT/GOOD/MISS**。续作想做时机条需从零新增。

## 5. 施加情绪的技能范式（续写技能照这个抄）

主流做法：**不用 effects ADD_STATE，把阶梯逻辑写进 YEP 动作序列 note**：

| 技能 | 要点 |
|---|---|
| 26 悲伤的诗 | `<whole action>`：目标有11→加12，有10→加11，否则加10（+1级SAD）|
| 112 雪球 | formula 按目标情绪加伤；命中后 `<target action>` 阶梯 +1级SAD |
| 84 团队精神 | 目标与自身各 +1级HAPPY（阶梯写两遍）|
| 437 吼叫 | `isEmotionAddable("angry")` 先清其他情绪再 14→15→16 |
| 328 穿心 | elementId:5（通用EMOTION，对任何情绪×1.5+），命中后**移除目标全部情绪** |
| 36 利用 | `b.isAnyEmotionAffected() ? atk*3.5 : atk*2.5` |

配套 note 标签：`<AntiFail>`（强制成功显示）、`<BattleLogType:XXX>`（战报文案类型）、`<HideInMenu>`。

## 6. 旁证速查
- 普攻公式 `a.atk*2-b.def`；GUARD 减伤 `damage/(2*grd)`。
- AUBREY 受击反击 `<Hit Counter>`、KEL 闪避反击 `<Evade Counter>`（YEP_X_CounterControl:229-269）。
- 情绪脸图/图标：note `<StateFaceIndex>/<StateBackIndex>/<StateListIndex>`（img/system/faceset_states.png）。
- 敌人 HIT 普遍 +0.95（Enemies traits）；武器普遍 HIT+1.0。
