## 现在就能交给我做的（已具备验证闭环）

### 1. 插件效果审查 ⭐ 已实测
- **手段**：浏览器测试环境（`docs/AI测试环境_20260930.md`）开书/开演出 → 按键驱动 → 截图视觉审查 + 运行时状态断言（句子状态、开关、页码、事件总线）
- **可审**：书场景全流程（打开/修改/擦除/保留/翻页/confirm/读档恢复）、blocks 四方向演出、封存演出流程、红字错误诊断
- **不可审**：手感节奏（6fps）、音效（WebAudio 锁）——这两项仍是你进引擎终审
- **用法**："改完 X 后自己在浏览器环境回归 night0 全流程，报告异常+截图"

### 2. 书 yaml 静态校验 ⭐ 工具已建
