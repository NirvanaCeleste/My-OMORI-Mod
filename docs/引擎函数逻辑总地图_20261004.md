## 原版写法红线（违者必出诡异 bug —— 都有实战教训背书）

1. **不在实例上 monkey-patch**：引擎从原型链调方法（如 update），实例包装无人调用（UnwrittenSeal 倒计时 bug 实录）。要改行为永远走 prototype alias。
2. **无 alias 不覆盖**：直接 `Class.prototype.method = ...` 会斩断所有前序插件的链。
3. **手动装配复杂场景禁止**：spriteset/图集/镜头系统依赖正规生命周期（三次实测失败）；自包含场景可以，但必须补 `_sceneStarted = true` 防二次 start。
4. **不绕过 busy 门除非明确知道在做什么**：changeScene 的 busy 检查保护演出完整性；forceSwap 是测试环境的手术刀，不是玩法代码该用的。
5. **不碰 plugins.js 手工结构**：OneLoader 自动管理（教程 1.10 警告）；发布打包走 BundleTool。
6. **新情绪/新系统要查硬编码表**：情绪六处（_isEmotionalState/isEmotionAddable/isEmotionAffected/YIN emotionStates/CBAT case/BASE transform switch）漏一处就是隐性 bug。
7. **别原地改 LanguageManager 缓存对象**（污染共享状态）。
8. **数值上限别在 rpg 层改**：最终由 YEP_CoreEngine 参数决定（rpg→OneMakerMV→YEP 三层链）。
