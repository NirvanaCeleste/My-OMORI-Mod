# OMORI 原作 黑白空间叙事语法（2026-10-03）

> 数据源：Map087/264/265/465/466/500/388 等 + CommonEvents（CE44/217/219/225）+ js/plugins（Olivia_HorrorEffects 等）+ languages/sc 全量控制码统计。
> 用途：《未竟之事》IPSU 篇章的"心理状态→视觉规则"对照依据。第六节是直接可抄的语法表。

## 一、White Space 的构建（Map087）

- **数据层极简**：55×55 图，6 层瓦片里**只有 2 种 id（1 和 2048），各铺满整层** —— "一整块单色地板"，无地形无装饰。极简主义是瓦片统计意义上的。
- **BGM**：地图字段留空，由 EV1 播 `white_space`（**pitch 60、volume 60** —— 低音调慢速的"压抑平静"）；后期换 `whitespace_3/4`；Something 战时 EV10 播 `boss_something_heartbeat` —— **心跳声先于视觉出现**。
- **"只有必需品"清单**：笔记本电脑（含日记）、素描本、纸巾盒、灯泡（拉绳+朝向判定）、小刀（sw24 后出现）、猫（喵乌）。无任何普通 NPC。
- **入口**：没有任何地图直接 Transfer 进 WS —— 全部走 **CE44 `★ Back to Whitespace`**（设 Teleport 变量 9-14）。睡眠、剧情节点、黑空间回归共用同一条通道。
- **门的语法**：选项"打开门/什么也不做"；开门传送 Neighbor's Room，**Fade Type 1 = 白色淡入**。
- **同一空间三复用**：Map087（日常）→ Map264（黑空间扭曲镜像版）→ **Map388（True Route 终局版，道具复刻+新增 shadow/FLOOR/String/Bow，无 BGM）** = 心理状态的三个阶段。

## 二、Black Space 的构建

- **地图族谱**：262/263 是空壳，实体从 264 起。465 RED SPACE 是 **28×194 的走廊**；466 NEIGHBORS BEDROOM 事件几乎全是 RED HAND STEP 排走道。
- **note 字段全空** —— 黑空间视觉靠三件事：**图集（maps/*.json 指向 BS_* 贴图）、parallax（`!parallax_black_space` 双轴滚动）、事件密度**（对比 WS 33 事件，BS 图 48-89 事件）。
- **BGM 命名即语法**：`bs_` 前缀成族（entrance/drone/listening/5ths），对照 WS 的 `white_space`。
- **Map264 = White Space 的扭曲镜像**：复刻 Laptop/Sketchbook/Tissue/Lightbulb，坐标簇与 WS 几乎同构 + 17 个 Ghostie + 大量传送门。

### 红色之手（Red Hands）
- 贴图 `DW_OBJECTS_WSNB`（char 3）+ 素材族（bs_hand/hands/FEAR_HANDS/red_hands_attack）。
- **排列语法**：三只一组（sprite offset +0,+8 / +28,+0 / +60,-8）拼成一只大手，沿走廊等距复制；"Lil Basil" 副本散布其间。
- **抓取统一处理 = CE219 `★ Blackspace Red Hand`**：移除 noise/glitch → 开 SW415/237 → 传送回 Map264 安全点。文本："我……我很抱歉……你会原谅我吗？" / "好疼啊，求求你了……让它们放开我吧"。
- WS 里也埋了红手（黑空间路线时四角伸出 HANDS-KUN）。

### 门机制（CE217 `★ BlackSpace Door Open`）
- 锁定时 flavor 文本"这扇门上锁了。"；开门 = `forceBlackspaceDoorOpen`（PresetAnimations.js:1926 的 7 帧动画）。
- **目的地由变量 1068（黑空间进度）单调递增驱动**：Suspense → Subconscious Spill → Empty Field → Neighborhood of Shadows → Forest of Stumps → Cat Dissection → Watermelon → Scribbles → Spider → Safe Spot → Meat Room → Elevator → Fish → Raft → Twoside → Time → Incubation → Playground → 兜底 Snowy Hill。
- **门 = Basil 记忆录像带的目录**（素材注释"诞生"磁带）。

### 失调度公式（CE225）
`noise = min(100, 0.01×var1067)`，再叠 `glitch(强度=var1067, 频率=max(1, 9000-var1067×100))`，循环加深 —— **"越深入越坏"写成了公式**。

## 三、Something 的出现语法

开关链：SW430 SOMETHING FADE → SW443（WS 显形）→ SW449/451/460 → SW1009（behind you，**勘误：不是 1010**）→ SW1081-1083 Phase1/2/3 → SW1282 Stab → SW1572 [Something Battle] → SW1583 is_Coming → SW1702 Basil_something。

**三种出现句式**：
1. **页条件显形**（不跟随、不阻挡、纯注视）：sw443 开启时 WS 四角浮现；Map268 传送格上的 Something 用 `<Sprite Offset: -16, +100>` 从画面下方探出 —— **它不追你，只是"一直在"**。
2. **抓取**：专用贴图 `basilsomethinggrab` + sw698/699。
3. **触发战**：sw1032 + `<Activation Square: 4>` 接近触发；战前先关显形开关 —— **战斗取代注视**。

**"Something behind you"(1009) 的实际用法**：作为对话分支条件（浴室是否看见它 → 改变次日 10 处 NPC 台词），而非贴图。
**核心语法：先给开关，再给台词，最后才给形象。**

## 四、恐怖/演出效果插件五件套

1. **Olivia_HorrorEffects**：noise / glitch / tv 三效果；`$gameScreen.createHorrorEffect('noise')` / `setHorrorEffectToValue(...)`。
2. **Aries001_AnimationScreenEffects**：Shake/Blur/ZoomBlur/Glow/Wave/Distort。
3. **fuku_EventTremble**：`Fuku_Plugins.EventTremble.start(事件ID, 强度, 速度)`（ID -1=玩家）。
4. **TDS Text Effects** + GTP 注册的扩展码：SINV/SINH/SHAKE/QUAKE/RAINBOW/LETAG/Com 等。
5. **YEP_MessageCore** `\fs[n]` 字号族。

**控制码语料统计**（sc 全量）：`\sinv[1]` 438 次、`\quake[1]` 239 次 —— **成对开关是规范**。
精神崩溃尖叫的四码叠加：`\Com[2]\quake[1]\fn<OMORI_GAME>\sinv[2]\{GAAAAHHHHH!!!`（25_cutscenes_blackhole）。
**效果码密度 = 心理失序度的刻度：白空间文本几乎零效果码，黑空间/战斗段极高。**

## 五、情绪-色彩

- 战斗内显式（StateBackIndex/BattlebackgroundName 切 UI 底色）。
- **战斗外不用 tint 表达心理**：8 张空间图 code 224 = 0 次。黑白红是烧在素材里的颜色 —— 黑白空间的"稳定、非情境性"由此而来。
- tint 全工程仅 26 图使用，语义两种：**白闪**（舞台/花园）与**红色薄纱**（闹鬼迷宫，`[255,0,0,100]` 系）—— 红纱专属恐惧场景。
- **RED SPACE 隐喻**：Basil 被 OMORI 的否认（红手）拖向"王座"的负罪内核；走廊尽头的 Throne + "男孩一遍又一遍重复着谎言" 的屏幕文本。
- **镜子句式**（可直接抄的空间三态探针）：
  - 黑空间："一面漂浮的镜子。你孤身一人。你想玩捉迷藏吗？"
  - 梦世界："一面浮空的镜子。朋友们在你身后露出了温暖的微笑。"
  - 现实："一面镜子。我不喜欢盯着镜子看太久。"
