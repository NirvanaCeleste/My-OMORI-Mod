## 四、AI 协作方法论（怎么把我用到极致）

**三种会话模式，开工先声明：**
- **建造**："照 docs/项目状态.md 开工，做 P1 的第 N 项，做完自测+同步 F 盘+提交"
- **审查**："读 XXX，只报告问题不动手，按严重度分级"
- **创作**："写 XXX 初稿，锚定角色语言风格，写完给我 3 个可选方向"

**四条黄金法则：**
1. **每个任务都要我自带验收标准**，你只做最终把关——"手感对不对"永远你说了算
2. **验收批量化**：攒 5-10 个改动进游戏一次测完，比改一个测一个省 80% 时间（测试清单模板在 docs/插件改动_*.md）
3. **每次会话结束让我更新 `docs/项目状态.md`**——它是跨会话的永久记忆，喂它 30 秒省下每次 20 分钟的通读
4. **永远不直接改 F 盘**：改 D → `python tools/sync_to_f.py` → 提交。F 只属于引擎

## 六、创意弹药库（我替你多想的）

1. **把"玩家的修改行为"写进故事**：第三夜结局页可以统计 `$gameUnwrittenStory` 全部句子状态，显示"这一周，你改写了 N 句，擦掉了 M 句，留下了 K 句"——Basil 数自己改过多少，正是自我惩罚心理的镜像。技术上零障碍。
2. **"黑暗中的门"**：不用新插件——blocks 四方向就是为它准备的：门出现的字从四面八方以 ttb/btt/rtl 混合方向逼近，互相叠压，纯 yaml 可实现。
3. **信件涂黑逐块揭示**：审查版信件的 █ 块做成事件里逐块"显影"的演出（Rowan 偷信夜的碎片化阅读体验）。
4. **封存演出的重量**：replayBook 重现你改的那句再盖章——"封住的是你的选择"，这是全 mod 情绪最重的一秒，值得单独打磨。
5. **等待室的沉默叙事**：法庭等待室剧本里"搓手/看地面/整理文件"的观察细节，用 mapgen 小事件+独立开关即可全做进地图，零美术需求。
6. **藏药的"不写明"原则**：剧本已自觉（吞药过程只在梦里出现），建议代码侧再加保险——所有涉药文本集中进一个 yaml，发布审查时一目了然。
