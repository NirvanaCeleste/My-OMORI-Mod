## 二、BattleManager phase 状态机（完整表）

| phase | 设置点 | 含义/下一跳 |
|---|---|---|
| init | setup 时 | 初始化 |
| start | startBattle | →update→startInput |
| **input** | startInput | 玩家输入；全员确认→startTurn |
| turn | startTurn(OBS:252/BEC:1867) | makeActionOrders 按速度排序 |
| **phaseChange** | BEC:2282 startAction | `_phaseSteps=[setup,whole,target,follow,finish]` 五段序列 |
| **actionList** | BEC:2168 | 执行 <setup/whole/follow/finish action>（全体目标） |
| **actionTargetList** | BEC:2187 | 执行 <target action>（逐目标） |
| action | 仅原版路径/强制行动 | YEP 下普通行动不经过 |
| turnEnd | endTurn | 全员 onTurnEnd → startInput 回 input |
| aborting / battleEnd / escape_animation(GTP:2516) | — | 中止/结束(胜0逃1败2)/逃跑演出(CE997) |

**关键**：装 YEP 后伤害结算入口是序列里的 `ACTION EFFECT` 指令；`checkBattleEnd` 在序列期间不判胜负。

**新增静态属性**：_battleRetried/_battleRetrySetup(重试快照)、_battleIntro/setBattleIntro(开场动画)、_actorCommandIndex(固定输入游标)、_finalBattlePhase、stressEnergyCount(=3 开局，受 HP 伤害+1，EnergyCost 技能扣)。

**getActorInputOrder**：固定 OMORI→AUBREY→KEL→HERO（开关7 切黑空间阵容[8,10,9,11]）——Geo_AutoTurnOrder(:31) 又改为按 actorId/`<BattleStatusIndex>` 排序。

## 五、模组挂接点清单（以 Basil 内容为例）

### A. 加技能 → Skills.json note + 少量插件
| note 标签 | 效果 | 解析点 |
|---|---|---|
| `<BattleLogType: XXX>` | 战报文案类型（新类型往 makeCustomActionText 加 case 或 alias） | CBAT:32 |
| `<EnergyCost: n>` | 扣队能量 | BASE:2301/2320 |
| `<ChainSkill: id, 方向>` + `<ChainOnly>` | 追击接入 | ACS:186/105 |
| `<ChainSkillEnergyRelease>` | 满能量合体技 | OBS:2908 |

公式即代码（a/b/v/s）；新语义 alias makeDamageValue(DMG:1332)。

### B. 加情绪（新状态）→ **硬编码表必须补**
- States.json：克制倍率=特征"属性有效度"；note：`<TransformEmotion>`(敌人变身，需 Enemies 四连条)、`<StateFaceIndex/StateBackIndex/StateListIndex>`(角色脸/背景/列表)、`<ParticleFront/Behind/Top>`(粒子)。
- **代码硬编码点**（新情绪 stateId 必须补全）：GTP:690 `_isEmotionalState`、GTP:719 `isEmotionAddable`、GTP:738 `isEmotionAffected`、YIN:49 `calcElementRate` 的 emotionStates、CBAT 情绪文案 case、BASE:2757 transform switch。
- 敌役专属情绪先例：119-126/197（Space Ex-Boyfriend ANGRY 等）。

### C. 加战斗事件 → Troops.json 页 + 强制行动 API
- Troops 页（回合/HP%/开关条件）由 setupBattleEvent 驱动；YEP_BaseTroopEvents 的"Base Troop ID"部队页**合并进所有部队**（放全局战斗公共事件）。
- 推荐 JS：queueForceAction / queueForceScriptCall / forceCustomBattleLog / `$gameTemp._addToFinishActions`（finish 段动态追加）。
- 时机挂点：startTurn(OBS:252) / endAction(GTP:2551) / endBattle(OBS:204) / processRetry(OBS:406) —— 一律 alias 不覆写。

### D. alias 规范
- TDS 系存 `_TDS_.OmoriBattleSystem.XXX` 命名空间（OBS:759-798）；YIN 链式引用它 —— **模组同样挂 `_TDS_` 命名空间再 alias，保证后续可链式**。
- GTP 用 class extends（:2333/2487/2195）—— 覆盖 GTP 行为需在其后加载再 extends。
