## 三、选型建议（《未竟之事》战斗内容施工时）

1. **敌人侧必装**：KOFFIN_BetterEnemySystem（情绪奖励还原+情绪AI+动作自动化三合一）+ Stahl_StateTiering
2. **Basil 技能侧**：Stahl_ChangeableBasicAttack（武器换普攻）+ FoG_PassiveSkills（被动）
3. **兼容性注意**：
   - KOFFIN 系都要求加载在 YEP 系之后（我们插件在 182/183 末端，装社区件放 178-181 区间）
   - BetterEnemySystem 会覆盖 YED_SideviewBattler 的动作默认——若我们敌人用自定义 Sideview note 则不受影响
   - 装任何社区件前跑一遍 AIPLAY testBattle 回归
4. **ESSENTIAL plugins 文件夹**（库根目录）= 修 Bug 合集： HorrorEffect 内存泄漏修复 / Tiled 旋转修复 / Geo_AutoTurnOrder（已在工程！182 位）/ rph.no omori crash（nomori 的兄弟版）

## 四、与本模组插件的关系

- 我们的 UnwrittenStory/UnwrittenSeal 是**玩法层原创**，社区库没有同类（书系统/封存演出是独有设计）
- 社区库 = **引擎能力补丁超市**；我们的插件 = 内容系统。两层不打架，按需取用
- 双方都在 `_TDS_`/全局 alias 体系内，加载序错开即可共存
