## 一、三个标杆场景拆解

### 野餐（双形态）
**梦境野餐（Map096 事件13，220 命令）**：
1. 存档/恢复门面（CE003/004）→ 午睡支线（BGMSAVE→BGMFADE→清天气→6 组 STOPSE+WAIT）；
2. 全员落座：`$gamePlayer.locate` + followers `setPosition` + `setCustomFrameXY` 坐姿帧（每人不同）+ `exaFC.clearAll` 解散队列；
3. **野餐无专属曲，延续地图 BGM**；
4. 对话节奏：凯尔嚼食道谢 → 贝瑟尔"真希望我能变得像你一样" → 玛里自谦 → 奥布里转圈小剧场（转身四向帧序列）→ **无后果的情感确认选项**（OMORI 点头/摇头，`AddChoice XX_GENERAL.message_10/11`）；
5. 收尾 = **黑屏换姿势再亮**（FADEOUT→重排→FADEIN，剧情封存进自开关），不渐黑不留尾台词。

**记忆野餐（Map384 秘密湖，136 命令）**：
- **音乐先在黑暗里响 2.5 秒才见画面**（WAIT 120 → 起 BGM → WAIT 150）；
- 以"照片"形式开场（black_screen + white_overlay 两张全屏图叠层）；
- 静场对话（句间 WAIT 15-45）→ **拍照仪式：快门 SE + 白闪图** → 转自由互动（每队友独立小段，Basil 段 = PHOTO SLIDE 幻灯）→ **任意按键唤醒收束**；
- 全图 0 次 tint —— 记忆感 = BGM + 照片叠层 + 环境音（amb_lake）。

### 过夜 Sleepover（Map078 + 20_cutscenes_sleepover）
三子场景递进：
1. **进门闲聊**：纯插科打诨铺垫，每人 1-2 短句；
2. **英雄弹钢琴（教科书级音乐时刻）**：镜头 8 秒缓推 → "别笑我喔" → **环境声掐掉（BGMFADE 1）→ 手部特写帧 → 演奏曲走 SE 通道（code 250）→ 17 秒零对白纯演奏（WAIT 900+100）** → 一句吐槽解压 → 转折段（空琴架/合奏回忆）→ 留白：热闹散去后玩家独处，上床时才播出 `duet_mari` 记忆二重奏；
3. **睡前夜话（治愈纯范本）**：毯子城堡 → 送礼物仪式 → 凯尔秒睡（`\|` 长停顿 6 连模拟鼾声 + 躺倒帧）→ **英雄低声独白，每行之间 WAIT 60（整整 1 秒留白），无走位只换表情帧** → 软收尾"晚安，\n[8]！明早见" → 不渐黑，"夜晚自然过去"交给玩家上床。
- **夜景 = 图片叠层**（dark_overlay + lighting_overlay 带闪烁动画帧），0 次 tint。
- **交叉淡化技巧**：新曲 vol0 预载 + 旧曲 BGMFADE。

### 合奏/钢琴（三段式：礼物→告白→演奏）
1. **圣诞小提琴**：凑钱轮述（每人一句"我出过什么力"）→ 开箱（`\{\sinv[1]` 惊呼 = 惊喜标准写法）→ **单行"……"留白一拍** → 触觉描写 → **白闪 + 第一个音符直接切场，不给对话**；
2. **后台告白（Map380）**：8 秒纯音乐入场 → 轮流真心话（奥布里 5 句 → 凯尔 → 英雄 3 句"大哭一场也没有关系" → 凯尔"仅仅因为你做了坏事……并不代表你就是坏人"）→ 合影站位 → **镜头缓慢还给玩家收尾**；
3. **独奏舞台（Map381，全程零对白）**：**演奏走 SE 通道**（不受 BGM 状态机干预、随场景精准结束）→ **弓法帧动画按乐谱语义对拍**（`//long-1 f` 下弓、`//med-3 b` 上弓，22 组逐音对齐）→ 一曲终了 → **天气转雨（code 223）做情绪翻面** → 无淡入直切。
- 温情资产**可积攒**设计：小提琴"修复了自身的一部分"逐段回收（曲奇香→西瓜→膝枕→雨声→蜡烛→圣诞）。

## 三、温情文本节奏量化（sc 实测，直接当规范用）

| 指标/条 | 玛里野餐 | 过夜 | Basil记忆 | 尴尬晚餐 | 树屋 | 战斗 |
|---|---|---|---|---|---|---|
| 短句率(≤6字) | 20% | 55% | 37% | **62%** | 60% | 31% |
| 省略号密度 | 0.59 | 0.58 | 0.61 | **1.22** | 0.89 | 0.61 |
| `\!` 密度 | 0.85 | 0.85 | 0.57 | **1.31** | 1.05 | 0.44 |
| `\>` 加速 | **0** | **0** | **0** | **0** | **0** | 0.71 |

**四条铁规范**：
1. **温情戏从不加速文字**（`\>` 一个不用——那是战斗专属）；呼吸全靠 `\!`（0.6-1.3/条）。
2. **省略号=情绪压强计**：日常 0.6 → 尴尬/沉重 1.2+。
3. **短句率区分功能**：夜话/树屋 55-62% 口语碎段；玛里式包容叙述 20% 长句。
4. 标志性码：`\c[4]物件\c[0]` 关键物高亮、`\Com[2]` 插科打诨、`\{\sinv[1]` 出格瞬间、**单独一条"……"=一拍静默的标准写法**；`\fs` 与所谓慢速码温情场景零使用（慢速= `\!`/`\|`/WAIT 手排）。

## 四、"治愈时刻"五段式公式（编排骨架）

**【0 物理落座】** 全员精确定位 + 坐姿帧 + 解散队列。治愈首先是一种"队形"。

**【1 插科打诨铺垫】（60-90 秒）** 短句率>55%，每人 1-2 句 + 小动作帧；**BGM 不换**；`\Com[2]` 放开用。把气氛抬到可以摔的高度。

**【2 一次真诚对话】（60-120 秒）** 一人主述他人补刀；**每行之间 WAIT 40-60（1 秒级留白）**；可插无后果的情感确认选项；台词负责把创伤名词化。

**【3 集体小仪式】** 演奏/拍照/送礼物三选一（技术模板见上）。核心：**掐掉环境声 + SE 通道 + 长时间零对白 + 一句吐槽解压**。

**【4 软收尾】** 三种正版收法：a) 晚安台词→WAIT→躺下帧→自开关；b) 黑屏换姿势再亮；c) 白闪+第一个音符直接切场。**情绪翻面用天气转雨（code 223），不用 tint。**

## 五、技术口诀（工具箱）

- 文本地图解耦：`code 356 ShowMessage <yaml>.message_N`，温情场景单建 yaml（如 `30_cutscenes_hospital.yaml`）。
- **音乐三层分轨**：地图情绪=BGM(241)、环境=bgs（AMB_QUIETNIGHT/amb_lake）、**演奏/关键音效=SE(250)**——SE 通道不受 BGM save/fade 污染。
- **滤镜靠图层不靠调色**：dark_overlay/lighting_overlay + setupPictureCustomFrames 动画帧（温情地图 0 次 tint）。
- 镜头语言：`CAM EVENT xxx 8000-10000` 缓推开场，`CAM PLAYER 1500-3000` 归还。
- 节奏双层叠加：命令级 WAIT（20-60）× 文本级 `\!`。
- 温情资产可积攒：医院线可复刻为"每段回忆修好一件东西（花/相机/琴）"。
