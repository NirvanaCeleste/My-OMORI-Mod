## B. 五大专题的真身位置

### ① SceneManager 主循环（全在 GTP_OmoriFixes #172）
GTP 通篇用 **ES6 class 继承重绑**（`SceneManager = class extends SceneManager`，:1254；同法还有 Graphics/DataManager/Scene_Map/Scene_Battle/BattleManager 等 22 个类）：
- `update(deltaTime)` :1256 新主循环（tickStart→determineRepeatNumber 决定迭代数→updateManagers+updateMain×n→renderScene）
- `requestUpdate` :1288 **弃 rAF，自建 PIXI.ticker（maxFPS=60）** + nw 最小化/失焦定时器
- `updateMain` :1339 新序列：updateOverlayFix→**updateInputData（失焦 return）**→changeScene→updateScene→updateWebAudio（失焦渐弱+suspend）→updateVideos
- **`isFocus` :1390**（hasFocus+visibilityState）→ `updateScene` :1400 失焦冻结场景 —— **测试环境"卡死"的根源**
- onKeyDown 屏蔽 F5、snapForBackground 截图规则

### ② Scene_BaseEX（Omori Main Menu.js:705-886）
= Scene_Base + 三件套：**函数队列**（queue/callNextQueueFunction/updateQueueProcessing —— OMORI 菜单全部逐步演出）、**等待系统**（wait/setWaitMode/startFunctionWait）、**移动对象**（this.move = new Object_Movement()，Omori BASE:5456）。
使用者：全部 Omori 菜单场景 + **我们的 Scene_UnwrittenStory/Scene_UnwrittenSeal**。

### ③ exaFC 跟随系统（Exhydra_FollowerControl #58）
linkEvent/followerInstruct/moveType/lockProperties/clearAll 命令族；Game_Follower 全套 alias。周边：Extra_Followers(动态增删)、Character_Movement_Graphics(跑爬换图)、Custom_Character_Rectangles(**setCustomFrameXY/WH/XYWH** :56-72 —— CharacterPatterns 的等价物)。

### ④ 图片/图集层
- **Custom Picture Controls**（TDS #22）：setupPictureCustomFrames/setPictureAnimation/帧动画等待模式；Game_Picture/Sprite_Picture 别名。
- **Atlas Loader**（#112）：data/Atlas.yaml 清单 + **重写 ImageManager.loadBitmap 族**（普通路径自动映射图集）；Scene_Base 增加 initAtlastLists/addRequiredAtlas —— **带图集的新场景要实现这两个**。

### ⑤ Input（rpg_core 零改动）
GTP 重写 _updateGamepadState（手柄阈值/最后设备记录）；Omori BASE 新增 inputKeyCode（按键提示 UI 反查）；Omori Name Input 独立 KeyboardInput 类；DisableMouse 置空 TouchInput。

## E. 给插件开发者的一句话版

- rpg_*.js 几乎纯 stock，动它意义小；**一切"引擎行为"都可从插件层 alias**。
- 数值上限实际由 YEP_CoreEngine 参数决定。
- 新场景继承 Scene_BaseEX 免费得队列/wait/move；要图集就实现 initAtlastLists。
- 新事件指令走 pluginCommand 链（357/358/658/1002 已被 OneMakerMV 占用，新指令从 359+ 或 pluginCommand 走）。
- 失焦"卡死"= GTP 的 isFocus 体系（:1400-1411）。
