## 1. 引擎栈

- **RPG Maker MV 1.6.1**（PIXI v4 定制版渲染，60fps 主循环）+ OMORI 大量定制插件（183 项）
- 本工程是 **OneLoader 解密的明文 playtest 工程**：OneLoader 运行时已剥离（残留 `save/mods.json`、`console.js`），等价于原生 MV 工程
- 双轨数据加载，开关是 URL/argv 参数 `test`：
  - `?test`（本工程模式）：`data/*.json` 明文 XHR、语言明文 `.yaml`
  - 正式版：`data/*.KEL` 等 AES-256-CTR 加密（密钥来自 nw argv）——浏览器测试环境走不到也不需要
- **Tiled 地图运行时合成**：`data/MapXXX.json` 只装事件（瓦片数组全 0），`YED_Tiled` 插件再 XHR `maps/mapNNN.json`（小写）+ 外链 tileset 合成渲染。图层 `G1-G7` 地面 / `A1-A5` 上层 / `Collisions` 碰撞；参数 Z 值 Below=1/Player=3/Above=5
- 语言系统：`Text_Language_Processor` 启动时 fs 遍历 `languages/<lang>/*.yaml` → `LanguageManager._data[lang].text[文件名]`；事件用插件命令 `ShowMessage 文件名.key` 挂接；**书 yaml 就是这个体系里的普通 yaml**，被 UnwrittenStory 按 states 树消费
- 主循环被 GTP_OmoriFixes 重写：PIXI Ticker 驱动 + `determineRepeatNumber` 帧补偿 + **isFocus() 失焦全停**（更新/输入/渲染三重门）

## 2. OMORI 特有约定（踩坑表）

- **开关**：System.json 已扩容到 2001 个。1-999 原作区（switch 4=STAB 菜单、switch 5=TAG、84=演出脚印等）；MOD 分配 2001-2003 夜书 / 2005 提示 / 2006 封存 / 2007 演示。**改开关先查 `docs/开关变量对照表.md`**
- **变量**：143=WTF 值（事件常用 `WTF >= 10` 条件）、1502=遭遇选择
- 图块 **32×32**（非 MV 默认 48）；tileset 图集上限 1024×1024；battleback 640×480；脸图 106×106/行 4 张；音频 **ogg/libvorbis**（ffmpeg `-c:a libvorbis`）；影片 webm 640×480
- 事件页编号**高者优先**；脚本框 vanilla 上限 12 行（OMORI 有 13 行的，勿动）
- 头号崩溃签名：`$atlasData is not Defined` = yaml 重复 key；`'tilewidth' of undefined` = Tiled 旋转图块；战斗无 OMORI 会读 hp 崩
- Picture ID 1 被强制压到角色图层下，演出用其他 ID
- 宏：`\n<名>`、`\n[8]`=Sunny、`\omo\kel\aub\her\bas\mar` 名字宏、`\v[#]`、`\c[#]`、`\Com[x]` 调公共事件

## 3. UnwrittenStory v1.41 架构（2360 行精读结论）

```
事件 → pluginCommand 'UnwrittenStory Open <yaml> <页> [speed] [mode]'
     → Scene_UnwrittenStory.prepare → create:
        bookData = LanguageManager.languageData().text[yaml]   // order/defaults/states
        states[0] 为根；沿 parent 链合并页（子覆盖父）= buildStatePages
        可见页 = currentVisibleOrder（祖先链页集 - 根状态 readonly 锁死页，按 order 排序）
     → Window_UnwrittenBook.setPage:
        parseInline: 逐行扫 **片段** 与 edits[] 按序配对（片段数必须==edits数，A2）
        buildLayout: 一次性算全部字符坐标（v1.40 核心；经典 ltr 流式 + blocks 四方向）
        computeSubPages: 经典模式按高度自动分页；blocks 模式整页一子页
     → 交互：↑↓ 选句 → 修改(变体窗360px)/擦除/保留
        → $gameUnwrittenStory.setVariant/setErased/setKeep（句子键 = 书名::id 域隔离）
        → advanceState: findMatchingState 只在当前状态子节点匹配 trigger{sentence,action,value}
        → startTransition 两阶段逐字过渡（全行同灭→全行同生）
     → 叶子读完 → enterEndingStage 显示锁死页 → confirm 页 → startAutoPlay 重播全序
        → updateEnding: doneSwitchId 三级搜索（当前页→pageOrder→_fullOrder，A1 修复）→ 置开关 → emit('finish')
     → 存档：makeSaveContents 注入 $gameUnwrittenStory；extractSaveContents 恢复原型（A5）
        _bookState[yaml]={id,page} 进度恢复（A3）
事件总线：_TDS_.UnwrittenStory.on('modified|erased|kept|state|page|finish', fn)
```

## 5. 双盘工作流（2026-09-30 反转版）
