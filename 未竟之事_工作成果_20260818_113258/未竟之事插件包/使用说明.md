# 《未竟之事》UnwrittenStory 插件 v1.7 —— 使用说明

## 打开书（事件插件命令）

```
UnwrittenStory Open uw_book p1
UnwrittenStory Open uw_book p1 4 simultaneous     # 临时覆盖速度/模式
```

## 数据模型：一个文件 = 一本书 / 一个故事（段落式）

```yaml
defaults: { speed: 4, mode: sequential, allowExit: true }
order: [p1, p2, ..., ending, confirm]
pages:
  页key:
    image: "插图名"          # 可选：img/pictures/；imageX/imageY 定位（默认居中）
    readonly: true           # 纯阅读页（结局页）：不能修改/擦除
    allowExit: false         # 本页禁止中途退出（ESC 无效）
    confirm: true            # 末尾确认页
    confirmChoices: ["确定", "再读一遍"]
    doneSwitchId: 1005       # 选"确定"后置 ON
    edits:                   # 可编辑片段定义（按 ** 出现顺序对应）
      - id: e1
        variants: ["替换文本……"]
        speed: 6             # 可选：该片段书写速度
        mark: true           # 参与封存判定
    text: |                  # 段落文本：**夹住**的片段可修改/擦除
      "……**接着贝瑟尔就这样被黑暗吞噬，**消失在了朋友们的眼前。"
```

- **段落模式**：`text` 一整段故事，`**xxx**` 标记可编辑片段（按顺序对应 `edits` 的 id/variants）
- **结局页**：`readonly: true`，无任何可改内容
- **确认页**：写完自动弹"是否确定"；确定 → 置 `doneSwitchId` → 合书；"再读一遍" → 回第一页
- **退出开关**：`defaults.allowExit` + 页面 `allowExit` 覆盖
- 旧格式 `lines`（每条句子一行、有 id 可改）仍兼容
- 渲染方向当前仅支持 ltr（从左到右逐行书写）

## 操作

| 按键 | 行为 |
|---|---|
| ← → | 翻页 |
| 确定 | 书写中＝快进；写完＝选句（自动跳到第一个可改片段） |
| ↑ ↓ | 选句（跳过纯展示文本） |
| 确定 | 菜单：修改 / 擦除 |
| ESC | 退出选句 / 退出书（当前页允许退出时） |

## UI（v1.7）

- 书窗口 + 动作/变体/确认菜单全部**无边框透明**，文字浮在背景上
- 背景：参数 `backgroundImage`（默认 `uw_bg`，占位图已生成）或 `backgroundColor`
- 每页插图：页面 `image` 字段（占位图 `uw_img_placeholder` 已生成）
- 页码与提示**居中**显示
- 文字颜色：参数 `textColor`

## 封存 + 戳刺（原作主菜单机制）

```
UnwrittenStory EnableStab   # 开关4 ON，主菜单"交际"变"戳刺"
```
主菜单选"戳刺" → `reserveCommonEvent(34)` → 公共事件34里写封存演出：
- `$gameUnwrittenStory.allRequiredMarkedByYaml('uw_book','p1')`
- `$gameUnwrittenStory.sentenceState('p1','e1')` → `{variant, erased, marked}`
- `$gameUnwrittenStory.setMarked('p1','e1',true)`
